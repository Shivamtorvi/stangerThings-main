# 🔥 Stranger Things — Interactive Landing Page

A cinematic **Stranger Things–inspired landing page** built with **React, Vite, and Framer Motion**.

The project features smooth animations, interactive mouse effects, and an atmospheric **Upside Down–inspired** design.

> ⚠️ Fan-made project for educational and portfolio purposes. Not affiliated with Netflix.

## ✨ Features

* 🎬 Cinematic hero section
* 🌀 Interactive mouse-following effect
* 🎞️ Smooth Framer Motion animations
* 🧭 Animated navigation bar
* 🎨 Custom CSS styling
* 📱 Responsive-friendly design
* ⚡ Fast Vite development setup

## 🛠️ Tech Stack

* ⚛️ React
* ⚡ Vite
* 🎞️ Framer Motion
* 🎨 CSS3
* 🧹 ESLint
* 📦 npm

## 🚀 Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
cd vite-project
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
